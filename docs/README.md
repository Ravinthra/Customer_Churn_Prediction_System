# Documentation

This folder contains documentation assets for the Customer Churn Prediction System.

## Screenshots

Add your screenshots here:
- `demo.png` - Main UI screenshot (recommended: 1200x800px)
- `demo.gif` - Animated demo of prediction flow

## How to Create Screenshots

1. Run the application: `cd backend && python manage.py runserver`
2. Open http://127.0.0.1:8000 in your browser
3. Use a screenshot tool or browser extension
4. Save as `demo.png` in this folder

## How to Create Demo GIF

1. Use a tool like [ScreenToGif](https://www.screentogif.com/) or [LICEcap](https://www.cockos.com/licecap/)
2. Record: Form fill → Submit → Result display
3. Optimize to under 5MB
4. Save as `demo.gif` in this folder
